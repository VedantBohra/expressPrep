# Hard Level - Express Backend

This is the **Hard level** of the project assignment.  
It sets up a basic Express server that you can run locally and test using Postman.

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd <your-repo-folder>
```

### 2. Switch to the Hard branch
```bash
git checkout Hard
```

### 3. Install dependencies
```bash
npm install
```

### 4. Run the server
```bash
node server.js
```

---

## 🧪 Testing
- Open **Postman** (or any API testing tool).  
- Test the available routes (check your `server.js` file for endpoints).  

👉 **Instruction:** Run the server using `node server.js` and then test the routes in Postman.
